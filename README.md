# Puzzle Game
## Front-end web animations
This project is one of three projects that I chose to make for one of my college courses.
The project is a puzzle game with fun and interactive animations, which are created using SCSS and Framer Motion. The project also includes a 2nd page where all used animations are displayed.

---

## Features
- Puzzle page with an interactive puzzle and a hidden easter egg.
- Assets page with all animations used in the puzzle.

---

## Project Setup

To get started with the project, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/CrispyMiatr/frontend-animation-templates.git
   ```

2. **Install dependencies**
   ```bash
   cd frontend-animation-templates
   npm install
   ```

    2.2. **Run the development server:**
   ```bash
   npm run dev
   ```
